# 0005. 시험 당일 운영 주의사항

> 출처: `mail.txt`의 운영진 명의 안내
> 성격: 시험 문제·범위가 아닌 **당일 운영 체크리스트**
> 공개 안전: 개인 배정 장소와 시험용 자격증명은 제외

## 1분 체크리스트

### 출발 전

- [ ] **08:00 전** 중요한 파일과 문서를 저장·백업한다. `메일:39`
- [ ] 이메일·문자로 받은 **개별 배정 캐빈**을 확인한다. `메일:7-9`
- [ ] **09:40까지 도착**하도록 이동한다. `메일:17`
- [ ] `[권장]` 입실 전에 화장실을 다녀온다. 시험 중 자리 이탈은 즉시 종료다. `메일:23`
- [ ] `[권장]` 휴대폰·워치·태블릿의 전원·알림·진동을 확실히 차단한다. `메일:24`

### 입실 후

- [ ] 운영진이 안내한 **시험용 계정**으로 iMac에 로그인한다. 개인 계정은 사용할 수 없다. `메일:26-29`
- [ ] 한/영 전환 단축키가 작동하는지 확인한다. `메일:31-33`
- [ ] 시험 중 자리를 이탈하지 않고 전자기기를 작동시키지 않는다. `메일:23-24`

### 끝낸 뒤

- [ ] 답안을 확인하고 반드시 **`[종료]` 버튼**을 누른다. `메일:21`
- [ ] 운영진이 배포한 **A4 1장과 펜**을 반납한다. `메일:18-20`
- [ ] 퇴장할 때 서명한다. 입장 시 서명이 아니다. `메일:22`

## 시간·제재 핵심

| 항목 | 운영 공지 |
|---|---|
| 시험일 | 7월 31일 금요일(메일 본문에는 연도 미기재) |
| 권장 도착 | 09:40 |
| 입실 마감 | 10:00:00까지 가능 |
| 지각 | 10:00:01부터 입실 불가 |
| 자리 이탈 | 화장실 포함 즉시 시험 종료 |
| 전자기기 | 작동 또는 울림 발생 시 즉시 퇴실 |
| 종료 버튼 미클릭 | 13:00 종료 시점 점수로 자동 처리 |
| 교육장 2·4·5층 | 08:00~10:00 사용 불가, 14:00부터 다시 사용 가능 |

## iMac·Neito

- 시험용 로그인 정보는 원문 메일에서 확인하고 문서나 공개 저장소에 복사하지 않는다.
- 메일은 iMac 로그인 후 한/영 전환 설정과 Neito 사용 안내를 확인하라고 한다.
- 메일의 `image.png`는 Neito 안내 첨부 문맥이지만 현재 로컬 `image.png`는 동료평가표다. 같은 파일로 간주하지 않는다.

## 이 메일로 확정할 수 없는 것

- 문제 수·형식·범위·배점·합격 기준
- 시험이 정확히 3시간인지 여부
- 인터넷·검색·외부 AI·개인 메모 허용 여부
- Neito 질문 제한과 답변 정책
- 시스템·네트워크·계정 장애 시 대응 및 시간 보상
- 자리 이탈 규칙의 의료·긴급 예외

현장 규칙이 추가로 안내되면 운영진의 최신 지시를 우선한다.
