# 0003. 시험 정보와 루머 집대성

> 기준일: 2026-07-31
> 역할: 사실·루머·추정을 구분하는 원장
> 정답과 실습: [0002](./0002-시험-예상-CHEAT-SHEET.md), [0004](./0004-동료평가표-OCR-예상문답-실습로그.md)
> 당일 행동: [0005](./0005-시험-당일-운영-주의사항.md)

`메일:n`은 `mail.txt`, `대화:n`은 단체 대화 기록의 행 번호다. 대화는 시험 전날 밤에 끝나므로 실제 기출이나 시험 후기가 아니다.

## 1. 판정 기준

| 표기 | 뜻 | 신뢰 범위 |
|---|---|---|
| `[직접-운영]` | 운영진 명의 메일에 직접 적힌 내용 | 시험 당일 운영에만 사용 |
| `[공식-과제]` | `instruction.md`에 직접 적힌 내용 | 학습 목표이지 시험 범위 확정이 아님 |
| `[직접-평가]` | 동료평가표 사진에서 판독한 내용 | 동료평가 문항이지 시험 문항 확정이 아님 |
| `[루머]` | 단체 대화의 전언 | 공식 확인 전까지 미확정 |
| `[개인추정]` | 말한 사람도 예상이라고 밝힌 내용 | 출제 근거로 단정 금지 |
| `[미확인]` | 자료에 없거나 누락된 내용 | 답을 만들어 채우지 않음 |

운영 메일은 발신 표시와 본문은 확인했지만 원본 헤더까지 독립 검증하지는 않았다. 평가표 사진도 작성 기관·적용 기수·작성일은 확인되지 않는다.

## 2. 루머가 아닌 직접 확인 정보

### 시험 운영

| 내용 | 근거 | 경계 |
|---|---|---|
| 7월 31일 금요일 시험 | `메일:3` | 연도는 메일 본문에 없음 |
| 09:40 도착 권장, 10:00:00 입실 마감 | `메일:15-17` | 10:00:01부터 입실 불가 |
| 완료 후 `[종료]` 버튼 필요 | `메일:21` | 미클릭 시 13:00 시점 점수로 자동 처리 |
| 자리 이탈 및 전자기기 작동·울림 제재 | `메일:23-24` | 즉시 종료 또는 퇴실 |
| 시험용 iMac 계정과 Neito 사용 안내 | `메일:26-34` | 자격증명은 공개 문서에 기록하지 않음 |
| 08:00 전 파일 백업, 일부 층 사용 제한 | `메일:36-39` | 상세 행동은 0005 참고 |

메일에는 문제 수, 문제 형식, 범위, 배점, 합격 기준이 없다.

### 공식 과제의 명시적 학습 목표

| 학습 목표 | 근거 |
|---|---|
| 절대 경로와 상대 경로 | `instruction.md:70` |
| 파일 권한과 `755`, `644` | `instruction.md:71` |
| Dockerfile 기반 커스텀 이미지 | `instruction.md:72` |
| 포트 매핑이 필요한 이유 | `instruction.md:73` |

CLI, Docker, Git 실습도 공식 과제에 포함되지만 이것만으로 실제 시험 문항을 확정할 수는 없다. 과제 예시의 포트 번호·이미지명·출력 문자열은 고정 시험 조건이 아니다.

과제 중 일반 Neito의 토큰·속도·입력 길이에 관한 경험은 시험용 버전에도 같다고 확인되지 않아 원장에서 제외했다.

## 4. 동료평가표와 시험 예상의 관계

로컬 `image.png`는 사용자가 동료평가표라고 확인한 사진이며 `5. 평가문항`의 다음 범주가 판독된다.

- 기능 검증: CLI, 권한, Docker 실행·빌드·포트·볼륨, Git 연동
- 구조 설명: 디렉터리 구성과 재현 가능한 포트·볼륨 설정
- 핵심 원리: 이미지/컨테이너, 포트 매핑, 경로, 권한 숫자
- 심층 인터뷰: 포트 충돌, 데이터 손실, `가설 → 확인 → 조치`

대화의 예상 문항 6개는 평가표의 핵심 원리·심층 인터뷰 문구와 거의 일치한다. 따라서 **평가표에 그런 문항이 있다는 사실**은 직접 확인되지만, **그 문항이 시험에 나온다는 주장**은 여전히 `[개인추정]`이다.

OCR 교정본과 답변·실습 로그는 [0004](./0004-동료평가표-OCR-예상문답-실습로그.md)에 있다.

메일 `31-34행`은 `image.png`를 Neito 사용법 첨부 문맥에서 언급하지만, 현재 로컬 파일은 동료평가표다. 두 파일을 같은 첨부물로 간주하지 않는다.

## 5. 현재 확인할 수 없는 것

- 정확한 시작 시각과 명시적 제한 시간
- 문제 수, 형식별 구성, 배점, 합격 기준, 부분 점수, 재시험
- 시험 범위가 1단계 미션에만 한정되는지
- 실기 명령을 실제 터미널에서 실행하는지
- iMac의 shell 및 Docker 환경 구성
- 오픈북, 개인 메모, 인터넷, 검색, 외부 AI 허용 여부
- Neito 질문 제한의 정확한 수와 초기화 조건
- 시스템·네트워크·계정 장애 시 처리 절차
- 시험 점수와 동료평가·최종 선발의 관계
- 실제 기출 문항

10:00 입실 마감과 13:00 자동 처리 시점은 확인되지만, 이를 곧바로 “시험 시간은 정확히 3시간”이라고 단정할 수는 없다.

## 6. 누락 자료

| 자료 | 확인 상태 |
|---|---|
| 동료평가표 사진 | 현재 한 장만 판독 가능 |
| 대화에서 언급한 평가 매뉴얼 사진 3장 | 전체 구성 미확인 |
| 예상 문항 뒤 삭제 메시지와 사진 2장 | 내용 복구 불가 |

누락 사진을 기출·정답지라고 부르거나 보이지 않는 내용을 복원했다고 주장하지 않는다.

## 7. 시험 직전 적용 순서

1. 운영 규칙은 `mail.txt`와 0005를 따른다.
2. 학습 범위는 `instruction.md`의 명시적 목표를 우선한다.
3. 평가표와 겹치는 문항은 대비하되 출제를 확정하지 않는다.
4. 단체 대화의 전언은 공식 정보가 새로 확인될 때만 승격한다.

현재 자료에는 확정 기출이나 시험 후기가 없다.
